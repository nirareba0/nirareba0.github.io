ACCESS誰が何を見られるか

本人のメモと、
お店の記録を分ける。

残り回数のように、お店と本人で分け合う記録。本人が自分で書くメモ。どれを誰に見せ、誰が直して消せるかを、作る前に決めます。

誰が何を見て、書いて、消せるか（一例）
できること本人（会員さん）お店・団体たいど
見る自分の記録だけ会員さんの記録。本人のメモをお店に見せるかは、作る前に決めます保守のあいだ、作業の権限で見える状態になります。見るのは不具合を直すのに要る範囲だけで、その範囲を契約の前に決めて書面にします
書く・直す自分のメモ残り回数・来た日・お店からのメモふだんの運用で、記録の中身を入れたり直したりはしません。不具合を直すのに記録を変える必要があるときは、お店の了承を得てから行います
消す自分のメモ。お店の記録を消したいときは、お店に頼みます会員さんの記録。やめた会員さんの記録をいつ消すかも決めます契約が終わるとき、手元に写しがあれば消して、消したことを書面で知らせます
  • 表は一例です。何を誰に見せ、誰が直せる・消せるかは、作る前に一緒に決めます。
  • 画面で「消す」を押すと、記録の場所（データベース）からも消える作りにします。使うサービスのバックアップに残る期間は、サービスによって違うので、作る前にお伝えします。
  • 利用者の記録を、たいどが作例や発信に使ったり、生成AI に入れたりはしません。契約書にも書きます。

    回数が変わった・メモが届いた、といった知らせは、決めた通数の内で送ります。

別にかかる料金LINE公式アカウントの月額（無料のプランは月200通まで）と、記録をためるサーバーの利用料は、たいどの代金とは別です。あなたから各社へ直接お支払いいただき、見積書にも分けて書きます。韮崎市の外へ伺うときの交通費も別です。
やめたときLINE公式アカウントと友だち、あなたの名義のサービスにある記録は、そのまま手元に残ります。何が動き続け、何が止まるか（保守が終わると、不具合や仕様の変更への直しは止まります）と、データの渡し方（CSV など）を、契約の前にお伝えします。
12か月の試算保守を12か月続けた場合、はじめの330,000円＋保守11,000円×12か月＝462,000円〜（税込）。別にかかる料金は含みません。

はじめの一式に入るもの

  • 聞き取りと設計（何を記録するか・誰が見て、直して、消せるか）
  • 記録をためる場所と、LINE の受け口
  • LINE の中で開くページ（自分の記録を見る・自分のメモを書く・消す）
  • お店が使う管理のページ
  • 回数が変わった・メモを書いたときの知らせ（月の上限つき）
  • トークの下のメニュー
  • 使い方の説明書

いまある紙や表計算の記録を移すこと、決済、ほかのサービスとつなぐことは、「〜から」に入りません。要る範囲を確かめて、別に見積もります。

保守の「軽い更新」の例（月2件まで）

  • あいさつや、自動で返す文を変える
  • メニューの画像を差し替える
  • ボタンの文を変える
  • 月の通数の上限の数字を変える

保守に入らないもの（別に見積もります）

  • 新しい画面や機能を足す
  • ほかのサービスとつなぐ
  • LINE側の大きな仕様の変更で、作り直しが要るもの
  • 24時間の対応・その日のうちの復旧の約束

実際の値段は、30分の相談のあと、作るもの・値段・日程を見積書でお出しし、書面で契約してから作ります。事業・団体のための仕組みづくりです。支払いの時期と方法、提供の予定日、着手の前とあとのキャンセルの条件、保守の終わり方も、契約の前に書面でお示しします。LINE側の仕様が変わったとき、保守でどこまで直すかと、止まったときの受け付けと対応の目安は、契約の前にお伝えします。

FAQよく聞かれること

頼む前に。

記録には、どんな情報を入れますか？

仕組みに要るものだけにします。悩みや体調など、慎重に扱う情報を記録するなら、ご本人の同意の取り方と、誰が見られるかを先に決めます。子どもが使うなら、保護者の扱いも決めます。

医療や治療の記録にも使えますか？

医療用の電子カルテや診療録としての利用は、前提にしていません。整体・相談の仕事などで使うときも、残す項目と扱いを、作る前に一緒に確かめます。

本人が消したら、本当に消えますか？

画面で消すと、記録の場所（データベース）からも消える作りにします。使うサービスのバックアップには、決まった期間残ることがあるので、その期間は作る前にお伝えします。

どれくらいで使い始められますか？

作る範囲と着手の時期を確かめて、試しの画面を触れる日と、使い始める予定の日を見積書に書きます。審査や設定に日数がかかる作りなら、その期間も分けてお伝えします。いまは相談と見積もりを受けていて、作り始めは2027年1月からの予定です。

いま使っている LINE公式アカウントに、足せますか？

いまの設定と、使っているサービスを確かめてから提案します。ほかの配信ツールや予約サービスとつないでいるときは、その連携への影響と、引き継げるかを先に調べます。Messaging API のチャネルが、すでにほかの会社の名義のプロバイダーにあるときは移せないので、その扱いも先にお伝えします。

LINE公式アカウントは、だれの名義になりますか？

あなたのお店・団体の名義です。LINE のチャネルは、あとから別のプロバイダー（チャネルを持つ事業者の単位）に移せないため、はじめからあなたの名義で作り、たいどは作業の権限をもらって加わります。くわしくは入口のよくある質問に書いています。

効果は約束されますか？

予約の数や売上、友だちの数などの数字は、約束しません。約束するのは、見積書に書いた仕組みを作って、使える形で渡すことです。

止まったときは、どうなりますか？

保守を頼んでいるときは、連絡の受け方と、見るまでの目安を契約に書きます。たいどは一人で動いているので、24時間の見張りや、その日のうちの復旧は約束できません。LINE やサーバーの会社の側の障害は、たいどが直せるものではないので、そう伝えて待ちます。
