WHAT何を作るか

ツールの外まで、
作る。

たいどが作るのは、配信ツールの設定だけではありません。記録をためる場所と、LINE の中で開くページを、自分の手で組みます。

  • 自前の記録（データベース）

    トークで受けたこと、予約、会員さんの回数。一人ひとりの記録を、あなたの持ち物としてためます。

  • LINE の中で開くページ

    トークの下のメニューから、自分の記録・予約・会員証が開く。アプリを入れてもらう必要はありません。

  • Web とつながる

    LINE でログインすると、サイトと LINE で同じ記録が見られる。サイトで起きたこと（承認・返事）を、本人の LINE に知らせます。

HOW IT WORKSどう動くか

トークから記録へ、
記録から本人へ。

  • お客さんがトークで打ったり、ボタンを押したりすると、あなたの名義の公式LINE から「受け口」に届きます。受け口は、LINE から来たものかを確かめてから、記録に残します。
  • こちらから送る知らせ（返事が来た・予約が決まった・前の日の知らせ）は、月の上限を通ってから届きます。トークへの返事は、月の通数に数えられません。
  • LINE の中のページと Web のページは、同じ記録を読み書きします。本人が自分の記録を消すこともできます。

RULES作り方で決めていること

名義・通数・安全・
会えること。

  1. あなたの名義で作る

    LINE の開発者向けの公式文書には「一度作成したチャネルを、後から他のプロバイダーに移動することはできません」とあります（出典）。だから最初から、あなたのお店・団体の名前で作ります。たいどは開発者として加わるだけです。

  2. 送る数の上限で止める

    LINE 公式アカウントは、プランごとに月に送れる数が決まっています（無料のプランは月200通まで。友だちの数×回数で数えます）。仕組みが送る知らせに月の上限を決め、そこで止まる作りにします。止まっても、トークで打てば返事は届きます。

  3. 子ども・相談のための決まり

    子どもや、悩みの話が届く LINE では、決めておいた言葉（命にかかわる言葉など）が届いたら何より先に相談先の窓口を返す、大人が読む範囲を先に決める、本人が自分の記録を消せる、を最初から入れます。決めた言葉に反応する仕組みなので、すべてを見つけられるわけではなく、大人の見守りや相談の窓口の代わりにはなりません。

  4. 韮崎の近くなら、会って話す

    山梨県韮崎市が拠点です。韮崎・北杜・南アルプスあたりなら、お店や団体に伺って、画面を一緒に触りながら決めます。遠くても、オンラインで。

組んだ仕組み。

韮崎の中高生の「なんで？」に、地域の大人が返事を書く場所（運営 たいど）。そのサイトと公式LINE をつなぐ仕組みを、たいどが組みました。こういう仕組みを作れる、という作例です。

  • トークで答えると、その人だけのノートに残る。ノートは LINE の中のページで読めて、消せる仕組み
  • 「みんなに見せる」を押すと、運営が確かめてからサイトに載り、本人に「載ったよ」が届く
  • 毎日／週に1回の問いは、月の上限で止まる。超えた分は、トークで「問い」と打てば届く
  • 決めておいた言葉（命にかかわる言葉など）が届いたら、何より先に相談先の窓口を返し、その文はノートに残さない

上の仕組みは、本番の LINE の上で、作ったたいどが試しの端末で一通り動くことを確かめたものです。LINE ログインとプライバシーポリシー・利用規約は、まだ公開前です。中高生の投稿や個人のことは、ここには載せません。

FAQよく聞かれること

頼む前に。

公式LINE は、だれの名義になりますか？

あなたのお店・団体の名義です。LINE の開発者向けの公式文書に「一度作成したチャネルを、後から他のプロバイダーに移動することはできません」とあります（LINE Developers コンソールの概要）。だから、はじめからあなたの名義で作り、たいどは開発者の権限をもらって作業します。契約が終わったら権限を外すだけで、LINE も友だちも、あなたの手元に残ります。記録をためる場所も、できるだけあなたの名義のアカウントに置きます。受け口や記録を動かす場所がたいどの名義になるときは、移す手順と費用を見積書に書きます。

あとから、費用が膨らみませんか？

作る費用は、見積書で先に決めます。範囲を広げるときは、作業の前に相談します。月の費用は2つに分かれます。LINE 公式アカウントの月額はあなたから LINEヤフーへ直接、たいどの保守（月11,000円〜）はたいどへ。仕組みが送る知らせには月の上限をつけ、上限を超えては送りません。管理画面から送る一斉のお知らせも同じ通数を使うので、配分を一緒に決めます。記録をためる場所の利用料がかかるかどうかも、見積もりのときに先にお伝えします。

自分で更新できますか？

一斉のお知らせは、LINE の管理画面からご自身で送れます。記録の項目や、ページのつくり、自動で返す言葉を変えるのは、保守（軽い更新を月2件まで）で受けます。配信の設定を毎週ご自身で細かく変えたいなら、月額の配信ツールのほうが合うこともあります。30分の相談で、どちらが合うかをお話しします。

LINE の規約は、大丈夫ですか？

LINE 公式アカウントの利用規約と、開発者向けのLINE ユーザーデータポリシーに沿って作ります。たとえば、集める情報と使い道を示して同意をいただく、LINE との連携を外す方法と退会の方法を用意する、パスワードを求めない、など。規約の読み方で迷うところは、作る前にお伝えし、LINEヤフーの窓口などで確かめます。

効果は約束されますか？

予約の数や売上などの数字は、約束しません。約束するのは、見積書に書いた仕組みを作って、使える形で渡すことです。
