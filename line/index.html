WHAT何を作るか

配信の設定ではなく、
仕組みを作る。

配信ツールの設定だけなら、月額のツールで足ります。たいどが作るのは、記録をためる場所と、LINE の中で開くページを、ひと続きにした仕組みです。

    LINEログインで、サイトと LINE で同じ記録を見られるようにできます。サイトで起きたこと（承認・返事）を、本人の LINE に知らせます。

RULES作り方で決めていること

名義・通数・やめ方・
会えること。

  1. あなたの名義で作る

    LINE のチャネルは、あとから別の名義に移せません（LINE Developers の説明）。だから最初から、あなたのお店・団体の名前で作ってもらい、たいどは作業の権限をもらって加わります。鍵やパスワードは受け取りません。

  2. 送る数に、月の上限をつける

    LINE公式アカウントは、プランごとに月に送れる数が決まっています（無料のプランは月200通まで）。仕組みが送る知らせに月の上限を決め、それを超えては送らない作りにします。友だちが送ったメッセージへのその場の返事は、通数に数えません（Messaging API の料金）。

  3. やめるときを、先に決める

    保守は任意で、最低の期間はありません。やめたときに動き続けるもの・止まるもの・データの渡し方を、契約の前にお伝えします。

  4. 韮崎の近くなら、会って話す

    山梨県韮崎市が拠点です。韮崎・北杜・南アルプスあたりなら、お店や団体に伺って、画面を一緒に触りながら決めます。遠くても、オンラインで。

HOW IT WORKSどう動くか

トークから記録へ、
記録から本人へ。

  • お客さんがトークで打ったり、ボタンを押したりすると、あなたの名義の LINE公式アカウントから「受け口」に届きます。受け口は、LINE から来たものかを確かめてから、記録に残します。
  • こちらから送る知らせ（返事が来た・予約が決まった・前の日の知らせ）は、月の上限の内で届けます。
  • LINE の中のページと Web のページは、同じ記録を読み書きします。何を誰が見て、直して、消せるかは、作る前に決めます。

FAQよく聞かれること

頼む前に。

LINE公式アカウントは、だれの名義になりますか？

あなたのお店・団体の名義です。LINE の開発者向けの公式文書に「一度作成したチャネルを、後から他のプロバイダーに移動することはできません」とあります（LINE Developers コンソールの概要）。だから、はじめからあなたの名義で作り、たいどは作業の権限をもらって加わります。LINE公式アカウントと友だちは、契約が終わってもあなたの手元に残ります。記録をためる場所（データベース）も、できるだけあなたの名義のアカウントに作ります。ソースコードと、仕組みを動かす場所（サーバー）の扱い、たいどの名義になる部分があるときの移し方と費用は、見積書と契約書に書きます。アカウントの ID・パスワードや、LINE の鍵（アクセストークン）は、たいどは受け取りません。

あとから、費用が膨らみませんか？

作る費用は、見積書で先に決めます。範囲を広げるときは、作業の前に相談します。月の費用は分かれています。LINE公式アカウントの月額はあなたから LINEヤフーへ直接、サーバーの利用料（かかるとき）は各社へ直接、たいどの保守（任意・月11,000円〜）はたいどへ。仕組みが送る知らせには月の上限をつけ、上限を超えては送りません。管理画面から送る一斉のお知らせも同じ通数を使うので、配分を一緒に決めます。

どれくらいで使い始められますか？

作る範囲と着手の時期を確かめて、試しの画面を触れる日と、使い始める予定の日を見積書に書きます。審査や設定に日数がかかる作りなら、その期間も分けてお伝えします。いまは相談と見積もりを受けていて、作り始めは2027年1月からの予定です。

いま使っている LINE公式アカウントに、足せますか？

いまの設定と、使っているサービスを確かめてから提案します。ほかの配信ツールや予約サービスとつないでいるときは、その連携への影響と、引き継げるかを先に調べます。Messaging API のチャネルが、すでにほかの会社の名義のプロバイダーにあるときは移せないので、その扱いも先にお伝えします。

自分で更新できますか？

一斉のお知らせは、LINE公式アカウントの管理画面からご自身で送れます。記録の項目や、ページのつくり、自動で返す言葉を変えるのは、保守（軽い更新を月2件まで）か、そのつどの見積もりで受けます。配信の設定を毎週ご自身で細かく変えたいなら、月額の配信ツールのほうが合うこともあります。30分の相談で、どちらが合うかをお話しします。

LINE の規約は、大丈夫ですか？

LINE公式アカウントの利用規約と、開発者向けのLINE ユーザーデータポリシーに沿って作ります。たとえば、集める情報と使い道を示して同意をいただく、LINE との連携を外す方法と退会の方法を用意する、パスワードを求めない、など。利用者向けのプライバシーポリシーは、たいどが下書きし、あなたの名前で出します。規約の読み方で迷うところは、作る前にお伝えし、LINEヤフーの窓口などで確かめます。

効果は約束されますか？

予約の数や売上、友だちの数などの数字は、約束しません。約束するのは、見積書に書いた仕組みを作って、使える形で渡すことです。

止まったときは、どうなりますか？

保守を頼んでいるときは、連絡の受け方と、見るまでの目安を契約に書きます。たいどは一人で動いているので、24時間の見張りや、その日のうちの復旧は約束できません。LINE やサーバーの会社の側の障害は、たいどが直せるものではないので、そう伝えて待ちます。
