先に、既製品を確かめます。

LINE で予約を受けるだけなら、月額の予約サービスで足りることがあります。承認制の予約ができる既製品もあります。30分の相談で、既製品で足りるかを一緒に見て、足りないときだけ作ります。作るのは、確かめ方に決まりがある予約（はじめての人だけ内容を聞く、など）です。回数券や会員の記録との組み合わせは、要る範囲を確かめて別に見積もります。

月の上限に来たら

送る数が月の上限に来ると、その月の「確定しました」と前の日の知らせは送りません。送れなかった予約をお店がどう知るか（管理のページに出す、など）と、お客さんへの連絡の手段（電話・トークなど）を、作る前に一緒に決めます。上限の内なら、前の日の確認を一人ずつしなくてすみます。

12か月の試算保守を12か月続けた場合、はじめの165,000円＋保守11,000円×12か月＝297,000円〜（税込）。別にかかる料金は含みません。

はじめの一式に入るもの

  • 聞き取りと設計（予約の受け方・確かめ方・変更とキャンセル）
  • LINE の中で開く予約のページ
  • お店が使う管理のページ（確定・日時の相談）
  • 「仮予約を受けました」「確定しました」と前の日の知らせ（月の上限つき）
  • トークの下のメニュー
  • 使い方の説明書

回数券や会員の記録との組み合わせ、決済、ほかの予約サイトと自動でつなぐことは、「〜から」に入りません。要る範囲を確かめて、別に見積もります。

保守の「軽い更新」の例（月2件まで）

  • あいさつや、自動で返す文を変える
  • メニューの画像を差し替える
  • ボタンの文を変える
  • 月の通数の上限の数字を変える

保守に入らないもの（別に見積もります）

  • 新しい画面や機能を足す
  • ほかのサービスとつなぐ
  • LINE側の大きな仕様の変更で、作り直しが要るもの
  • 24時間の対応・その日のうちの復旧の約束

実際の値段は、30分の相談のあと、作るもの・値段・日程を見積書でお出しし、書面で契約してから作ります。事業・団体のための仕組みづくりです。支払いの時期と方法、提供の予定日、着手の前とあとのキャンセルの条件、保守の終わり方も、契約の前に書面でお示しします。LINE側の仕様が変わったとき、保守でどこまで直すかと、止まったときの受け付けと対応の目安は、契約の前にお伝えします。

FAQよく聞かれること

頼む前に。

予約サービスと、何が違いますか？

月額の予約サービスで足りるなら、そちらをおすすめします。たいどが作るのは、確かめ方に決まりがある予約です。はじめての人だけ内容を聞いてから確定する、など。回数券や会員の記録との組み合わせは、別に見積もります。

電話や、ほかの予約サイトと一緒に使えますか？

使い方しだいです。空き枠をどう合わせるか（管理のページに手で入れる、など）を確かめます。ほかの予約サイトと自動でつなげられるか、その費用はどれくらいかは、見積もりでお伝えします。

変更・キャンセルは、どう受けますか？

トーク・電話・予約のページのどこで受けるかと、締め切りの伝え方を、作る前に決めます。受けた変更は、お店が管理のページで直します。

どれくらいで使い始められますか？

作る範囲と着手の時期を確かめて、試しの画面を触れる日と、使い始める予定の日を見積書に書きます。審査や設定に日数がかかる作りなら、その期間も分けてお伝えします。いまは相談と見積もりを受けていて、作り始めは2027年1月からの予定です。

いま使っている LINE公式アカウントに、足せますか？

いまの設定と、使っているサービスを確かめてから提案します。ほかの配信ツールや予約サービスとつないでいるときは、その連携への影響と、引き継げるかを先に調べます。Messaging API のチャネルが、すでにほかの会社の名義のプロバイダーにあるときは移せないので、その扱いも先にお伝えします。

LINE公式アカウントは、だれの名義になりますか？

あなたのお店・団体の名義です。LINE のチャネルは、あとから別のプロバイダー（チャネルを持つ事業者の単位）に移せないため、はじめからあなたの名義で作り、たいどは作業の権限をもらって加わります。くわしくは入口のよくある質問に書いています。

効果は約束されますか？

予約の数や売上、友だちの数などの数字は、約束しません。約束するのは、見積書に書いた仕組みを作って、使える形で渡すことです。

止まったときは、どうなりますか？

保守を頼んでいるときは、連絡の受け方と、見るまでの目安を契約に書きます。たいどは一人で動いているので、24時間の見張りや、その日のうちの復旧は約束できません。LINE やサーバーの会社の側の障害は、たいどが直せるものではないので、そう伝えて待ちます。
