# 名刺用QRコード

飛び先: `https://nirareba0.github.io/`（バージョン3・誤り訂正Q・29×29モジュール）

| ファイル | 中身 | 使いどころ |
|---|---|---|
| `qr-a-roast.svg` | 焙じ麦色 `#2a1b10`・背景なし | 麦茶色の紙にじかに刷る（本命） |
| `qr-b-ink.svg` | サイトの深緑 `#283e33`・背景なし | サイトと色をそろえたいとき。紙が濃いと読みにくくなる |
| `qr-c-tile.svg` | 焙じ麦色＋生成り `#f3f1e9` の台紙 | 紙が濃い・ざらつく・活版のとき |
| `preview.png` | 名刺（91×55mm）に置いたときの見え方 | 確認用 |

- SVGは周りの余白（4モジュール）込みで一辺22.2mm、QR本体は17.4mm。縮めるなら本体15mm（全体19mm）まで
- 余白の中に文字や罫線を入れない
- 入稿はSVG（またはそれを置いたPDF）で。PNGは確認用
- 作り直し: `pip install segno && python print/qr/make_qr.py`
